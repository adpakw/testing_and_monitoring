# Отчёт по домашнему заданию

## 1. Обработка ошибок (надёжность)

Добавлены или доработаны следующие обработки:

- При невалидном запросе (отсутствие обязательных фичей) возвращается HTTP 422 с пояснением.
- При запросе с неизвестными фичами (которые модель не ожидает) возвращается 422.
- При невалидном `run_id` в `/updateModel` возвращается 400.
- Если модель не загружена (при старте или после сбоя), `/predict` возвращает 503.
- Ошибки препроцессинга и инференса логируются и возвращают 500, сервис продолжает работу.
- При старте, если не удалось загрузить модель, сервис остаётся в degraded режиме, но принимает запросы на обновление.

## 3. Метрики (Prometheus)

Логируются следующие метрики:

- **Технические**:  
  - `http_requests_total` (метод, путь, статус) – счётчик запросов.  
  - `http_request_duration_seconds` (гистограмма) – время ответа с перцентилями.  
  - `http_errors_total` (счётчик) – количество ошибок (статус >=400).  
  - `process_memory_bytes`, `process_cpu_percent` – потребление ресурсов.

- **Связанные с входными данными**:  
  - `feature_numeric_value` (gauge) – текущее значение числовой фичи.  
  - `feature_categorical_total` (счётчик) – частота категориальных фичей.  
  - `preprocessing_duration_seconds` (гистограмма) – время предобработки.

- **Метрики модели**:  
  - `inference_duration_seconds` (гистограмма) – время инференса.  
  - `model_probability` (gauge) – предсказанная вероятность.  
  - `model_predictions_total` (счётчик) – количество предсказаний по классам.

- **События**:  
  - `model_updates_total` (счётчик) – обновления модели с меткой статуса.  
  - `model_active` (info) – run_id и тип текущей модели.  
  - `model_features_count` (gauge) – количество необходимых фичей.  
  - `model_required_feature` (gauge) – флаг для каждой фичи.
